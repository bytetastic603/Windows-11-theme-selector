# Windows 11 Theme Selector

A simple application for selecting and automatically applying built-in Windows 11 themes.

## Download

**[Download the latest version](https://github.com/bytetastic603/Windows-11-theme-selector/releases/latest)**

1. Open the latest release.
2. Scroll down to the **Assets** section.
3. Download `Theme selector.exe`.
4. Open the downloaded application.

> Always download Theme Selector from this official GitHub repository.

## Available Themes

Theme Selector provides access to built-in Windows 11 themes stored in the default Windows theme folders.

### Standard Themes

| Option | Theme |
|---|---|
| 1 | Aero (Light Theme) |
| 2 | Aero Dark (Dark Theme) |
| 3 | Windows Spotlight Mode |
| 4 | Glow (Theme A) |
| 5 | Captured Motion (Theme B) |
| 6 | Sunrise (Theme C) |
| 7 | Flow (Theme D) |

### High Contrast Themes

| Option | Theme |
|---|---|
| 8 | High Contrast #1 |
| 9 | High Contrast #2 |
| 10 | High Contrast Black |
| 11 | High Contrast White |

### Exit Application

| Option | Action |
|---|---|
| 12 | Exit Application |

## How to use?

1. Launch `Theme selector.exe`.
2. The theme selection menu will appear.
3. Enter the number corresponding to your preferred theme.
4. The application will automatically apply the selected theme to Windows.
5. Enjoy your new theme!

## Requirements and Compatibility

- **Operating system:** Windows 11 only.
- Compatible with both activated and unactivated versions of Windows 11.
- Not designed for Windows 10 or earlier versions of Windows.
